# بازبینی مجدد سناریوهای مقاله — ۲۱ اکتبر ۲۰۲۶

مبنای بررسی: commit `9dd7bb9` از شاخهٔ main. نتیجه: مسیر اجرایی همهٔ سناریوهای الزامی در مخزن وجود دارد، اما نسخهٔ پیش از این بررسی چند ایراد اجرایی داشت. نسخهٔ ۰٫۲٫۱ آن‌ها را اصلاح می‌کند. صحت کامل اجرا روی دیتاست واقعی و T4 هنوز اثبات نشده است.

## شواهد و حدود تأیید

۳۴ آزمون موفق و ۳ آزمون CUDA به علت نبود GPU ردشده از اجرا (skip). چهار کلاس baseline رسمی روی دادهٔ مصنوعی آموزش، backward و inference شدند. lint و بررسی ساختار برنامه نیز انجام شد. هیچ عدد عملکرد، برتری Double DQN، مصرف حافظه یا latency واقعی T4 از این آزمون‌ها استنتاج نمی‌شود.

برای اجرای نهایی روی T4، پس از نصب وابستگی‌ها و دریافت منابع رسمی طبق README:

```bash
DRLPOI_UPSTREAM_ROOT="$PWD/artifacts/upstream" python -m pytest -q
```

سه آزمون CUDA باید روی GPU قابل‌دسترسی اجرا شوند. سپس مراحل `calibrate`، `plan`، دو worker آموزش، worker جداگانهٔ timing و فرمان‌های report/compare-family/diagnostics را طبق README انجام دهید. تمام دادهٔ انتخاب‌شده استفاده می‌شود؛ آزمون مصنوعی نرم‌افزار، فاز پایلوت آزمایش مقاله نیست.

برنامه‌هایی که با نسخهٔ قبلی تولید شده‌اند به‌دلیل تغییر hash کد باید دوباره تولید شوند. پوشهٔ state جدید لازم است. checkpointها را فقط با config/data مطابق بارگذاری کنید و خطای ناسازگاری را با ویرایش دستی metadata دور نزنید.
